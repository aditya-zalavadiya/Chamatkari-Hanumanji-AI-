# શ્રી ચમત્કારિક ધામ રાજકોટ — Ganesh Mahotsav Poster Name-Card Generator

A high-performance, Apple-grade devotional web application built for **Shree Chamatkarik Hanumanji Mandir, Rajkot** for their **17th Ganesh Mahotsav ("ચમત્કારિક ધામ કા રાજા")** event.

---

## 🌟 Key Features

- **Pixel-Perfect Canvas Compositing**: Native HTML5 `<canvas>` rendering engine with exact percentage coordinates ensuring 1:1 match between live preview and downloaded posters.
- **Interactive Photo Positioning**: Drag-to-pan, pinch/scroll zoom, rotation, and warmth tone filters for seamless devotee photo fitting inside the ornate gold ring frame.
- **Auto-Fit Devanagari/Gujarati Typography**: Dynamic fit-to-width algorithm preventing text overflow on the gold ribbon banner for names of any length.
- **High-Resolution Multi-Scale Export**: Download in **1x HD** (1194×1600), **2x Ultra HD** (2388×3200), and **3x 4K Print** (3582×4800) formats with celebratory confetti.
- **Apple-Grade Glassmorphism**: Frosted glass cards (`backdrop-blur`), gold gradients, glowing accents, and devotional maroon color palette.
- **Temple Information & Social Integration**: Official temple address (*Kalawad Road, Rajkot*), Instagram handle ([@shreechamatkarikdham](https://instagram.com/shreechamatkarikdham)), and 1-tap WhatsApp sharing.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Glassmorphism Custom Utilities
- **Rendering Engine**: Native HTML5 Canvas 2D Context
- **Icons**: Lucide React + Custom SVG Icons
- **Effects**: Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## ☁️ Deployment (Cloudflare Pages)

1. Connect this GitHub repository to [Cloudflare Pages](https://dash.cloudflare.com/).
2. Set **Framework Preset** to `Vite`.
3. Set **Build Command** to `npm run build`.
4. Set **Build Output Directory** to `dist`.
5. Deploy and enjoy free global CDN and SSL!
